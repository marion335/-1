# MY GUITAR CHORD BOOK

自分オリジナルのギターコードブック。全12キー分のオープンコード／バレーコード（E型・A型）をあらかじめ収録した、ブラウザだけで動くコード事典です。

## 特徴

- **全12キー対応**：メジャー／マイナー／7／m7／M7／sus4／sus2／6／m6 をカバー
- **オープンコード**：定番の押さえ方を厳選して収録
- **バレーコード自動生成**：E型・A型のムーバブルフォームを全12キーぶん自動計算
- **検索・絞り込み**：ルート音／コードタイプ／フォーム（オープン・バレー）・キーワード検索
- **★ マイブック**：お気に入りコードを保存して自分だけのコードブックに
- **自分用メモ**：コードごとに練習ポイントや使う曲をメモできる
- **オリジナルコード追加**：自分で見つけた押さえ方をフレット番号で登録できる
- **印刷対応**：ブラウザの印刷機能でそのまま紙のコードブックにできる

データはすべてブラウザの `localStorage` に保存されるため、サーバーやアカウント登録は不要です。

## 使い方

`index.html` をブラウザで開くだけで動作します。ローカルで確認する場合は、この `guitar-chordbook` フォルダで簡易サーバーを起動してください。

```bash
cd guitar-chordbook
python3 -m http.server 8080
# http://localhost:8080 を開く
```

## ディレクトリ構成

```
index.html        メイン画面
css/style.css      デザイン
js/chords.js       コードデータ・バレーコード生成ロジック
js/app.js          画面制御（検索・お気に入り・メモ・追加フォーム）
```

## コードを追加する

「＋ コードを追加」タブから、コード名と6弦分のフレット番号（開放弦は `0`、鳴らさない弦は `X`）を入力すると、マイブックにオリジナルコードとして保存されます。
